# Sample data files

Every file here is **sample data** so the demo runs offline. Loaders in
`backend/loaders/` read the real public datasets from `data/raw/` when present.

| File | Stands in for | Notes |
|---|---|---|
| `gem_india_fields_sample.csv` | Global Energy Monitor – Global Oil and Gas Extraction Tracker (India rows) | Field names and operators are real; centroids are approximate; reserves, production and reservoir parameters are illustrative values, not GEM figures. Same column names as the GEM export for the fields we use. |
| `volve_ddr_sample.xml` | Equinor Volve daily drilling reports (WITSML `drillReports`) | Synthetic content written in the Volve DDR XML structure so the parser can be demoed. Replace with the real DDR XMLs in `data/raw/volve_ddr/`. |
| `geology_sample.geojson` | GSI Bhukosh lithology shapefiles | Simplified hand-drawn polygons of the main surface units in Upper Assam. Not survey-accurate. |
| `landslides_sample.csv` | NASA Global Landslide Catalog | Illustrative events in NE India in the NASA catalog column layout. |
| `zones_sample.geojson` | WDPA protected areas + OSM reserved forests | Approximate outlines of real protected areas; boundaries are simplified and NOT legally accurate. |
| `rivers_sample.geojson` | River centrelines (OSM waterways) | Approximate Brahmaputra and Burhi Dihing centrelines used for flood distance. |
| `drilling_report_sample.pdf` | A daily drilling report / well completion report | Generated by `backend/scripts/make_sample_pdf.py` to demo the document extraction page. |
